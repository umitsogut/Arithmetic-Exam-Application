# Math Quiz Game

A simple command-line math quiz written in Python.

## Features

- Choose between two levels:
  - **Level 1:** Addition, subtraction and multiplication using numbers 2–9
  - **Level 2:** Squares of numbers 11–29
- Answer 5 randomly generated questions
- Score calculated out of 5
- Option to save results to `results.txt`
- Input validation and error handling

## Technologies

- Python 3
- `random`
- File handling

## Run

```bash
python main.py
```
